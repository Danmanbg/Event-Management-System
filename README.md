Event Management System 🎟️

A simple web app for managing events and ticket orders. Built in Visual Studio 2022 for a school project.

Users can:
View events
Order tickets
View their events

Admins can:
Create events
View all events
Order tickets
View all orders

Ordering tickets:
Each event has its own order form
Clicking [Order] creates a new order in the database

How to Run:
Open the solution in Visual Studio 2022.
Restore NuGet packages.
Apply migrations:
Add-Migration InitialCreate
Update-Database
Press F5 or click Run to start the project with IIS Express.

Tech:
ASP.NET / MVC
Entity Framework
SQL Server
